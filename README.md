# 📊 Machine Downtime Analysis Dashboard

## 📌 Project Overview
This project analyzes machine downtime data across multiple factories and device types using Tableau. The goal is to identify high downtime areas, improve operational efficiency, and support data-driven decision making.

---

## 📊 Features

- 🔹 Downtime by Factory Analysis  
- 🔹 Downtime by Device Type  
- 🔹 Interactive Dashboard Filtering (Factory-based)  
- 🔹 Identification of high downtime machines  
- 🔹 Comparative analysis across locations

## 📈 Key Insights

- 🏭 Certain factories show significantly higher downtime compared to others  
- ⚙️ Specific devices (e.g., LaserWelder) contribute most to downtime  
- 📉 Some devices consistently show zero or minimal downtime  
- 🔍 Filtering helps identify factory-specific machine issues  

---

## 🎯 Purpose

- Analyze machine downtime patterns  
- Identify performance bottlenecks  
- Improve operational efficiency  
- Enable better maintenance planning  

---

## 📂 Dataset

- Source: Daikibo Telemetry Data  
- Fields Used:
  - Factory  
  - Device Type  
  - Status  
  - Unhealthy (Downtime Indicator)  

---

## ⚡ How It Works

1. Data imported into Tableau  
2. Created calculated field (`Unhealthy`)  
3. Built two visualizations:
   - Downtime per Factory  
   - Downtime per Device Type  
4. Applied interactive filter (Factory → Device Type)  
5. Designed dashboard for insights  

---

## 📎 Project Outcome

This dashboard helps stakeholders quickly identify:
- Which factory has maximum downtime  
- Which machines need attention  
- Where optimization is required
